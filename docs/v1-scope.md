# v1 Scope

The v1 Scope defines the specific features and functionality that will be included in the first version of Nutrimap. This ensures a focused and achievable product slice.

## Core Features

1. **Wellness Goals:**
   - Hair health
   - Hormonal balance
   - Immunity
   - Nervous system support
2. **Supplement Tracking:**
   - Add and view supplements related to wellness goals.
   - Simple supplement details (e.g., name, purpose).
3. **Achievements:**
   - Basic achievements to encourage user engagement.

## Simplifications

- **No Barcode Scanner:** Barcode scanning for supplements will be considered in future versions.
- **Simple Achievements:** Start with basic achievements; advanced gamification will come later.

## Why This Matters

Defining the v1 Scope ensures that development efforts are focused on delivering a functional and valuable product slice. It helps avoid overengineering and ensures timely delivery of the first version.
