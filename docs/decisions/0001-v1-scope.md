# ADR 0001: Define Nutrimap v1 Scope

## Status
Accepted

## Context
Nutrimap needs a clear first release boundary so development stays focused and avoids overengineering. The app is a portfolio + production-minded personal project centered on wellness support.

## Decision
For v1, Nutrimap will focus on these wellness goals:
- Hair health
- Hormonal balance
- Immunity
- Nervous system support

For v1, we intentionally exclude:
- Barcode scanner (later)
- Advanced achievements and gamification (later)

The app will handle personal wellness-related data carefully, but it is not a medical advice app.

## Consequences
- Positive: Faster delivery, clearer priorities, lower complexity.
- Positive: Easier to validate product direction before adding larger features.
- Tradeoff: Some convenience and engagement features are deferred to later phases.
