# Nutrimap

Nutrimap is a wellness-focused app designed to help users track and improve their health goals, such as hair health, hormonal balance, immunity, and nervous system support.

## Goals for v1

- Focus on wellness goals: Hair health, hormonal balance, immunity, and nervous system support.
- Keep the app simple and user-friendly.
- Handle personal data carefully (but this is not a medical advice app).

## Status

This project is in Phase 1: Product Slice / North Star. Documentation and planning are in progress.
